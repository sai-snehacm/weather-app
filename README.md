# Weather App 🌤️

A simple and beginner-friendly Python project that fetches **live weather information** for any city using a free API (`wttr.in`).  
This project demonstrates API integration, JSON parsing, exception handling, and command-line interaction.

---

## 🚀 Features
- Get real-time weather data for any city
- Shows:
  - 🌡️ Temperature (°C)
  - 🤗 Feels Like temperature
  - 💧 Humidity
  - 📍 Location details
- Uses a **free and public API** (no API key needed)
- Very easy to run and modify
